# NSE OI Analytics (native Android)

Standalone app: fetches NSE option-chain data directly on the phone and shows PCR, bias,
OI, max pain, support/resistance and the intraday setup. No laptop or server needed.

## Build the APK with GitHub (no Android Studio)
1. Create a free GitHub account and a new repository.
2. Upload everything in this folder (including the hidden .github folder).
3. Open the Actions tab > "Build APK" > wait ~5-8 minutes (or click Run workflow).
4. Open the finished run > Artifacts > NSE-OI-Native-apk > download, unzip, install app-debug.apk.
